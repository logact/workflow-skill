# 记录的创建与修改必须提交 git

## 决策内容

决策/任务/问题/backlog 记录的每次创建与修改都必须落到 git 提交里。实现分两层：

1. 脚本层（强制）：`wf-new.sh`、`wf-status.sh`、`wf-archive.sh` 在执行完文件变更后自动 `git add` 本次涉及的文件（记录文件 + INDEX.md）并 `git commit`，提交信息格式 `wf: <动作> <ID>（<标题>）`
2. agent 层（补充）：脚本之外的手工修改（如补全任务验收标准、填写决策正文）由 agent 在修改后立即自行提交

## 背景与理由

1. 记录是项目记忆的载体，不提交就会随工作区丢失或被覆盖，追溯链（机制4）形同虚设
2. 提交做进脚本而非只靠 agent 自觉：确定性行为不该依赖提示词约束
3. 只 `git add` 本次涉及的文件而不是 `git add -A docs/`：避免把无关的未提交改动卷进记录提交

## 影响范围

- scripts/wf-common.sh：新增 `wf_git_commit` 公共函数（非 git 仓库、路径被 gitignore 时静默跳过；提交失败仅告警不中断，因为记录文件已写入）
- scripts/wf-new.sh / wf-status.sh / wf-archive.sh：末尾接入自动提交
- SKILL.md、assets/README.md：新增"记录即提交"规则
