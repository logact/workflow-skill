# 机械模拟通过不等于人类可验证，缺少人类视角的验收路径

## 现象
tests/simulate.sh 的 46 项断言全是脚本对脚本的检查（grep frontmatter、数 INDEX 行数），全绿也只能证明脚本按脚本预期工作。人类验收者看完输出无法直观判断"这套工作流对不对、好不好用"，机械通过 ≠ 人类认可。

## 复现 / 验证方式
复现：运行 `bash tests/simulate.sh`，输出 PASS=46 FAIL=0，但全程没有人类可理解的叙事，也没有真实使用场景。
修复有效的判定：出现一种验收路径，让用户能以自己的判断（而非脚本的断言）确认工作流成立。
