# 执行任务与讨论决策时增加两条检查规则

## 条目描述

在执行任务、讨论/创建决策时增加两条检查规则：

1. **是否有动 domain**：执行任务前/中检查改动是否触及领域核心逻辑；若触及需明确标记并说明影响
2. **决策是否与既有决策/原则相违背**：创建或讨论决策时，对照 decisions/ 里的既有决策和 PRD 原则做冲突检查

待明确的点（回流升级时需讨论）：
- "domain" 的具体界定（哪些文件/目录算领域层）
- 检查落在哪：agent 行为规则（SKILL.md/assets README）、模板字段（task 模板加 domain 影响、decision 模板加冲突检查）、还是 wf-check.sh 脚本检查
