# 引入场景驱动概念：issue 关联到场景

## 条目描述

当前记录体系缺少"场景驱动"概念：issue（以及可能的 task）应该关联到某一个具体场景，而不是孤立存在。PRD 的场景章节已有雏形（建模、验收、记录问题等流程场景），但记录文件与场景之间没有关联字段。

待讨论的点（回流升级时展开）：
- "场景"如何定义与编号：是 PRD 场景章节的编号引用，还是独立的场景列表文件
- 关联范围：只关联 issue，还是 task/backlog 也关联
- 落点：模板加 `scenario` 字段（frontmatter 或正文），wf-check.sh 是否需要校验场景引用可解析
