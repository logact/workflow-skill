# 讨论任务自动化执行机制

## 条目描述

讨论如何让系统自动跑任务，替代当前手动派活的模式（见 PRD 场景 9：目前由用户在对话中把任务交给 agent 执行）。

候选方向（讨论时评估）：
- cron 定时扫描 docs/tasks/ 里"待办"状态的任务，自动派给 agent 执行
- 编排类 skill（如 orca orchestration）做任务分派与多 agent 协调
- hook 触发：任务创建/状态流转时自动唤起执行

待讨论明确后升级为任务。
